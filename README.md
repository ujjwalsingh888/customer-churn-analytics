# Customer Churn Analytics

Exploratory data analysis of the IBM Telco Customer Churn dataset using Python.

## Objectives

* Clean and prepare customer data.
* Analyze churn patterns across contracts, tenure, payment methods, and monthly charges.
* Visualize trends and identify customer retention opportunities.

## Technologies

* Python
* Pandas and NumPy
* Matplotlib and Seaborn
* Jupyter Notebook

## Key Findings

* Overall churn rate: 26.54%.
* Month-to-month customers have a 42.71% churn rate.
* Customers with 0–6 months of tenure have a 52.94% churn rate.
* Customers who churn have higher average monthly charges than those who stay.

## Project Files

* `InsightIQ_01_Customer_Churn_EDA.ipynb` — Data cleaning and exploratory data analysis.
* `requirements.txt` — Required Python libraries.

## How to Run

Install the dependencies:

```bash
pip install -r requirements.txt
```

Open the notebook in VS Code or Jupyter Notebook. Ensure the dataset path matches your local setup.
